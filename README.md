## 📖 詳細説明

**Galax-Shh** は、Galaxy 端末のカメラのシャッター音を、撮影する場所や状況に合わせて切り替えるためのユーティリティアプリです。

### 【こんな場面を想定しています】
- **無音撮影が条件とされているスポーツ観戦**（ゴルフのギャラリーなど）
- **野鳥・動物・ペットなど、音に敏感な被写体の撮影**
- **眠っている赤ちゃんやペットを起こしたくないとき**
- **撮影が許可されている静かな施設での、周囲への配慮**（美術館・博物館・図書館・セミナーなど）

---

## 🤝 大切にしていること

日本国内で販売される多くの端末では、盗撮防止などの観点からシャッター音が鳴る仕様になっています。シャッター音には、周囲に撮影を知らせ、無断撮影を抑止する役割があり、その意義を軽視するものではありません。

一方で、撮影が認められている場所でも、静かな環境が求められたり、撮影方法に個別のルールが設けられたりすることがあります。

**Galax-Shh は、撮影の可否を判断するアプリではなく、シャッター音の切り替えを支援するツールです。**  
撮影する人にも、撮影される可能性のある人にも配慮した、責任ある使い方を目指しています。

## ✨ 主な特徴

- **すばやい切替**: アプリ画面のほか、通知バーのクイック設定パネルやホーム画面ショートカットからワンタップで即座に切り替え可能
- **自動化アプリ連携**: Tasker、MacroDroid、「モードとルーチン」などの自動化アプリからインテント／プラグインでシームレスに連携
- **権限設定の自動許可（Target SDK 22）**: Android 6.0以降で義務付けられた「システム設定の変更」の手動許可操作を省略し、インストール直後から即座に動作
- **Galaxy特有のシステム音量連動仕様への完全対応**: 消音適用時にシステム音量が1以上の場合、自動で0に調整し、通常音復帰時に元の音量へ自動復元
- **リアルタイム状態通知（誤撮影防止）**: クイック設定タイルだけでなく、アプリ内操作、自動化アプリ、システム音量やマナーモードの変更にリアルタイム連動。システム音量が上がってシャッター音が鳴る状態になった場合は警告表示とワンタップ消音アクションを提供
- **ユーザー補助サービスによるホームボタン自動連携**: 標準カメラアプリ起動中にクイック設定タイル等から切替を行った際、設定を即時反映させるため自動でホーム画面へ戻る安全なアシスト機能（画面情報の取得や監視は一切行いません）
- **端末再起動時の自動復旧**: 端末の再起動完了時にバックグラウンドで消音設定を自動再適用
- **初回起動時の利用規約・マナーへの同意**: 初回起動時にマナー・禁止事項・免責事項への同意ダイアログを必須化し、責任ある利用を担保

## 🔒 プライバシーと通信について

- **本アプリはネットワーク通信を一切行いません。** インターネット接続の権限（`INTERNET`）を持たず、広告・解析・クラッシュ収集などの外部SDKも組み込んでいません。
- 個人情報、撮影した写真、画面の内容、利用状況などを**収集・保存・送信することはありません**。
- アプリが端末内に保存するのは、利用規約への同意状況、再起動時の自動適用の設定、消音前のシステム音量（復元用）のみです。

## 🔑 使用する権限と目的

| 権限・機能 | 目的 | 取得する情報 |
|:---|:---|:---|
| システム設定の変更（`WRITE_SETTINGS`） | Galaxyのシャッター音設定を書き換えるため（**中核機能**） | なし |
| ユーザー補助サービス | タイル切替時にカメラからホーム画面へ戻すため（`GLOBAL_ACTION_HOME`） | なし（画面取得・監視なし） |
| 使用状況へのアクセス（`PACKAGE_USAGE_STATS`） | 前面アプリがカメラかどうかを一時判定するため | なし（端末内の一時照合のみ） |
| 通知の表示（`POST_NOTIFICATIONS`） | 消音状態の表示と初期設定案内のため | なし |
| 起動時の自動実行（`RECEIVE_BOOT_COMPLETED`） | 端末再起動後に消音設定を自動再適用するため | なし |
| 音量の変更（`MODIFY_AUDIO_SETTINGS`） | 消音時にシステム音量を0にし、解除時に復元するため | なし |
| バッテリー最適化の除外（`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`） | 再起動時の自動適用失敗（ディープスリープ）を防ぐため | なし |
| バイブレーション（`VIBRATE`） | ショートカット実行時の触覚フィードバックのため | なし |

### 他のアプリからの呼び出しについて
Tasker等の自動化アプリ向けに、次のアクションを受け付けます。**初回起動時の利用規約への同意が完了するまでは動作しません。**

| アクション | 動作 |
|:---|:---|
| `com.aistudio.galaxshh.action.TOGGLE` | 消音／通常音を切り替え |
| `com.aistudio.galaxshh.action.MUTE_ON` | 消音にする |
| `com.aistudio.galaxshh.action.MUTE_OFF` | 通常のシャッター音に戻す |

## 🛠️ 機能と設定の詳細

### 1. 3種類のクイック設定タイル
通知バーを展開して即座に切り替えられる3種類のタイルを提供：
- **① 消音切替**: 消音中はアクティブ点灯。音が出る状態では消灯し、現在の音量値を表示
- **② カメラ消音**: ワンタップで確実に消音とシステム音量0を適用
- **③ カメラ音有効**: ワンタップで通常のシャッター音を適用し、システム音量を復元
- タイルタップ時のバイブレーションは完全OFF

### 2. ユーザー補助サービス（ホームボタン連携）
- **目的**: 標準カメラアプリが起動している間はシステム設定の変更が即座に反映されないため、タイル操作時に自動で一度ホーム画面へ戻し、消音設定を確実に反映させます。
- **プライバシー**: 画面テキストの読み取りやタッチ監視権限は一切持たず、ホームキー送信のみを行う安全設計です。
- **設定手順**:
  1. 通知またはアプリ内からユーザー補助設定を開き、「インストール済みアプリ」から「Galax-Shh ホームボタン連携」を選択します。
  2. 警告画面が出た場合はホームに戻り、アプリアイコン長押し → アプリ情報 → 右上メニュー「制限付き設定を許可」を有効にします。
  3. 再度ユーザー補助設定から「Galax-Shh ホームボタン連携」をONにして完了です。

### 3. バッテリー使用「制限なし」推奨
Galaxy端末で日数が経過した際、アプリがディープスリープに入り再起動時の自動消音適用が失敗するのを防ぐため、アプリ内または案内通知からバッテリー使用を「制限なし」に設定することを推奨します。

### 4. アンインストール前の初期化・設定復元について
**【重要：アンインストール時のOS仕様と注意点】**  
Android OSのセキュリティ仕様上、アプリのアンインストール時に自動で設定を元に戻すことはできません（アプリが削除される瞬間にコードを自動実行するフックやコールバックはOSの仕様上存在しません）。

そのため、本アプリをアンインストールする際は、**必ず事前にアプリ内の「消音を解除」または「シャッター音を初期値に戻す（設定復元）」を実行してからアンインストールを行ってください。** アプリ内にワンタップで初期値に戻してアンインストール画面を開くボタンを用意しています。

**【もし元に戻さずにアンインストールしてしまった場合の復旧手順】**  
万が一、消音状態のまま本アプリをアンインストールしてしまった場合でも、以下のいずれかの方法でいつでも通常のシャッター音（初期値）に戻すことができます：
1. **本アプリを再インストールして解除**: 再度本アプリをインストールし、トップ画面の「消音を解除」を押す。
2. **ADBコマンドで復旧**: PCまたはワイヤレスデバッグ（LADB等）からADBコマンドで復旧する。
